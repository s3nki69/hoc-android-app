# HOC Android Alkalmazás

## 📱 Üdvözöl a HOC Alkalmazás!

Ez az alkalmazás egyesíti a HOC.hu oldal tesztjeit, a kupon.hoc.hu kuponjait és a HOC YouTube csatorna videóit egy kényelmes mobilalkalmazásban.

## ✨ Funkciók

### 📰 Tesztek és Bemutatók
- A HOC.hu WordPress oldalról automatikusan leszedi a legújabb teszteket és bemutatókat
- Kereshető tartalmak
- Képekkel illusztrált cikkek
- Egy kattintással megnyithatod a teljes cikket böngészőben

### 🎟️ Kuponkereső
- A kupon.hoc.hu oldalról szedi le a kuponokat
- Keresés kuponok között
- Egy gombnyomással másolható kuponkód
- Direkt link az áruházba

### 🎥 YouTube Videók
- HOC TV Channel videóinak tallózása
- Kattintással megnyílik a videó YouTube-on

## 🔧 Telepítés

### Módszer 1: APK Telepítés (AJÁNLOTT - LEGEGYSZERŰBB)

1. **Töltsd le az APK fájlt** a telefonodra
2. **Engedélyezd az ismeretlen forrásokból való telepítést**:
   - Nyisd meg a Beállítások-at
   - Menj a Biztonság menüponthoz
   - Kapcsold be az "Ismeretlen források" opciót
   - VAGY újabb Androidon: Beállítások → Alkalmazások → Speciális → Speciális hozzáférés → Ismeretlen alkalmazások telepítése
3. **Kattints az APK fájlra** és kövesd a telepítési utasításokat
4. **Kész!** Az alkalmazás most már használható

### Módszer 2: Android Studio-val (Fejlesztőknek)

Ha szeretnéd saját magad lefordítani az alkalmazást:

1. Telepítsd az Android Studio-t
2. Nyisd meg ezt a projektet
3. Csatlakoztass egy telefont vagy indíts emulátort
4. Kattints a "Run" gombra

## 📖 Használat

### Első Indítás
1. Nyisd meg az alkalmazást
2. Várd meg, amíg betöltődnek a tartalmak (internet kapcsolat szükséges)
3. Lapozz a három fül között: Tesztek / Kuponok / Videók

### Tesztek Tab
- Görgess le a cikkek között
- Használd a keresőt konkrét témák kereséséhez
- Kattints egy cikkre a teljes tartalom megnyitásához

### Kuponok Tab
- Írj be egy terméknevet a keresőbe (ANGOLUL! pl. "vacuum", "projector")
- Kattints a "Kód másolása" gombra → kuponkód a vágólapon
- Kattints az "Áruház megnyitása" gombra → megnyílik a termék oldala
- Illeszd be a kuponkódot (CTRL+V vagy hosszú nyomás)

### Videók Tab
- Tallózz a videók között
- Kattints egy videóra → megnyílik YouTube-on

## 💡 Tippek

- **Internetes kapcsolat szükséges** az alkalmazás használatához
- **Lehúzás a frissítéshez**: Húzd le a listát az új tartalmak betöltéséhez
- **Kupon keresés**: Használj angol kifejezéseket a kuponoknál (pl. vacuum, projector, speaker)
